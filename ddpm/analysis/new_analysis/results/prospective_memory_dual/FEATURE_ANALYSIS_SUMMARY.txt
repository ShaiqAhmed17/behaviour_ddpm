================================================================================
METHODOLOGY
================================================================================

1. Extracted 36 features from each teacher/student NPZ file
   - 10 hand-crafted ring geometry metrics
   - 10 topological metrics
   - 16 diff/sum modes (each metric in cue1-cue2 and cue1+cue2 form)

2. For each feature independently:
   a. Removed that feature from the 36-D matrix
   b. Normalized remaining features with StandardScaler
   c. Computed pairwise Euclidean distances
   d. Fitted 2D MDS with dissimilarity='precomputed'
   e. Recorded MDS stress value
   f. Importance = stress_without - stress_all

3. Ranked features by importance (highest to lowest)

4. Tested different feature subsets (3, 10, 15, 20, all 36)
